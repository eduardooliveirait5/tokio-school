# 🎓 Tokio School — Exercícios e Projetos

Repositório dedicado aos exercícios, práticas e projetos desenvolvidos durante minha formação na **Tokio School**.

O objetivo deste repositório é documentar minha evolução na área de desenvolvimento de software, reunindo exercícios práticos, desafios e projetos realizados ao longo da formação.

---

## 📚 Sobre

Este repositório funciona como um histórico do meu processo de aprendizagem e desenvolvimento de competências em programação.

Os exercícios estão organizados por área e módulo, permitindo acompanhar a evolução desde os fundamentos até projetos mais completos.
